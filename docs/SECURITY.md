# Security

## Secrets
- `DECART_API_KEY` (permanent `dct_…` key) is read only in `src/lib/server/env.ts`, which
  imports `server-only` so a client import fails the build.
- The browser only ever receives a **client token**: TTL 60 s (`DECART_TOKEN_TTL_SECONDS`),
  optional `allowedModels`, `allowedOrigins` = `APP_ORIGINS`, and
  `constraints.realtime.maxSessionDuration` (default 180 s). Token expiry does not end a
  live session — the session cap does.
- The logger redacts keys named `apiKey|token|authorization|secret|password` and never
  logs token values.

## API protection
| Route | Controls |
|---|---|
| `POST /api/v1/tokens` | Origin/Referer must match `APP_ORIGINS`; 5 req/min/IP; 10 s mint timeout; generic error to client, detail in logs |
| `POST /api/v1/events` | 60 req/min/IP; body ≤ 4 KB; zod schema with enum event names and bounded property values |

The in-memory rate limiter is per instance (fine for one Vercel region during MVP,
**not** a real limit across serverless instances). Replace with Upstash Redis before
public launch.

## Browser
- `Permissions-Policy: camera=(self), microphone=()`.
- Production CSP: `default-src 'self'`; `connect-src 'self' https://*.decart.ai wss://*.decart.ai`;
  `media-src 'self' blob:`; `img-src 'self' data: blob:`. `script-src` still allows
  `'unsafe-inline'` for Next.js bootstrap — move to nonces before prod.
- Camera only after explicit consent (ToS/Privacy/AUP + 18+). Stream is stopped on every
  teardown path, including tab hide and `pagehide`.

## AI-specific risks
- **Abuse / NSFW**: the live video is generated by Decart. MVP relies on Decart's AUP and
  server-side policies plus short session caps. Phase 2: consume Decart moderation signals
  and end the session on a flag (Anywear does this by tearing down, not covering).
- **Prompt injection**: prompts are fixed per garment in `lib/garments.ts`; no user text
  reaches the model in the MVP.
- **Cost abuse**: token minting is the only door to GPU time; it is rate limited and
  every token is session-capped.

## Privacy
Survey answers (gender bucket, age range) are logged as analytics. Publish a privacy
policy and replace the placeholder ToS/Privacy/AUP links (`NEXT_PUBLIC_*_URL`) before launch.
